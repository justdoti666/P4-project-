## 2. 第 1–3 章合并要点（给组员填空用）

### 第 1 章建议小节

```text
1.1 项目背景（城市交通、换乘、路径规划）
1.2 问题定义（输入：路网 + 起终点；输出：路径 + 时间/里程/换乘；约束：换乘建模）
1.3 功能需求（加载、选点、三算法、路径高亮、动画、导出、自检）
1.4 非功能需求（134 站 <200ms、任意窗口不变形、站名不重叠、5 分钟可运行）
1.5 验收标准（任务书 5 条，逐条对应本报告章节）
```

### 第 2 章建议小节

```text
2.1 数据模型（Station / MetroLine / 站台节点 (站点, 线路) / 边类型）
2.2 图存储（邻接表，O(V+E)；为什么不用邻接矩阵）
2.3 Dijkstra（优先队列/二叉堆，时间 O((V+E)logV)）
2.4 A*（可采纳启发函数 h = 直线距离 / 最高速度；结果仍最优）
2.5 分层 BFS（按换乘层数扩展；层内按时间择优）
2.6 结果封装（RouteResult：stations/legs/total_time/total_distance/expanded/visited_order）
2.7 边界（同站、无路径、独立支线）
```

### 第 3 章建议小节

```text
3.1 分层架构（core 数据/算法 → ui.window 状态机 → ui.canvas 渲染 → tools 自检/导出）
3.2 数据加载与校验（JSON/TXT、DataFormatError 中文提示）
3.3 窗口与交互（控件、点击选点、算法切换、统计栏）
3.4 画布渲染（世界→屏幕、等比+y 翻转、缩放锚点、站名避让、路径/动画）
3.5 动画时间轴（events + after、1/2/4×、暂停/跳过、旧帧清理）
3.6 导出（PNG 截图 vs PS 矢量、DPI 适配）
3.7 异常处理（数据错误、无路径、同站、文件不存在）
```

第 3 章可用界面截图：`docs/figures/fig3-1_ui.png`（建议编号 **图 3-1**）。

## 4. 术语统一表

| 统一写法 | 不要写 | 说明 |
| --- | --- | --- |
| 换乘 | 换线、转线 | 全文统一“换乘” |
| 站点 / 站台节点 | 节点（单独出现时） | 物理站叫站点，搜索状态叫站台节点 |
| 路径 | 路线、方案 | 指算法结果；准则叫“最快/最少换乘” |
| 扩展节点数 | 访问数、搜索数 | 指 `expanded` 字段 |
| 动画 / 立即显示 | 动画模式 / 静态模式 | 验收表述统一为“动画与立即显示一致” |
| 接驳线 / 支线 | 辅线 | 画布虚线对应“接驳线/支线” |
| 像素 / 公里 / 分钟 | px/km/min 混用 | 正文用中文单位，图表轴可用缩写 |

## 6. 终稿合并顺序（建议 30 分钟）

1. 建一个空白文档，套用学校/课程模板，设置标题 1/2/3 样式；
2. 先粘第 1–3 章正文，按本模板补“本章要解决什么”和过渡段；
3. 粘第 4 章：把 `docs/P4-报告章节草稿.md` 的 4.5–4.7 整段复制，保留表 4-2/4-3、图 4-4；
4. 粘第 5 章：把 P4 草稿 5.1–5.4 复制，再把其他组员的踩坑并入 5.3；
5. 统一编号：从第 2 章开始按出现顺序重排表/图，更新交叉引用；
6. 插入 `docs/figures/` 图片，统一宽度（建议 14–16cm）；
7. 生成目录、检查页码、导出 PDF，最后跑一遍自检留证。
