## 2. 重新生成与检查（两条命令）

在仓库根目录 `metro-p4/` 下执行（Python 3.10+，需要 `python-docx` 与 Pillow）：

```powershell
python tools/make_report.py        # 生成报告终稿 docx（约 1 秒，不需要 GUI）
python tools/check_report.py       # 统稿检查；退出码 0 = 通过
```

`make_report.py` 会先调用 `make_report_assets.ensure_assets()`：图 2-1 不存在时自动重画，
其余 5 张插图缺失时直接报错并列出缺哪张，不会生成一份“缺图”的报告。

也可以单独先生成/校验插图，再生成报告：

```powershell
python tools/make_report_assets.py          # 重画图 2-1 + 校验 6 张插图
python tools/make_report_assets.py --check  # 只校验，不重画
python tools/make_report_assets.py --force  # 强制重画图 2-1
```

本机实测（Windows 11、Python 3.12.14、python-docx 1.2.0、Pillow 12.3.0）：

```text
[REPORT] 文件大小：981.4 KB
[REPORT] 一级标题 9 个，其中正文章 5 个：第1章…第5章
[REPORT] 内嵌插图 6 张；表格 15 个（含封面与分工表）
[REPORT] 段落 316 段；全文字符（含表格）26350 个；正文汉字 10365 个

结论：22 通过 / 0 失败 / 0 警告，共 22 项
闸门：绿（退出码 0）。
```

> 若环境里 `python` 不是目标解释器，用你本机解释器的绝对路径调用即可，
> 例如 `<Python 解释器路径> tools\make_report.py`（**不要把本机路径写进仓库**）。

## 7. 提交前仍需人工完成的事

1. **填写姓名/学号/班级/组号**（封面与分工表的 `＿＿＿＿` 占位）；
2. **更新目录**：Word / WPS 中打开 → 目录处右键“更新域” → 更新整个目录
   （LibreOffice 打开时目录域不会自动展开，属正常现象）；
3. **PDF 已导出并与终稿同步**：`reports/城市交通路径导航系统_实验报告.pdf`（34 页，
   目录带页码），提交前确认页码、图题、字体即可；若要重导，用 WPS / Word 打开 docx
   更新目录域后“另存为 PDF”；
4. 如需重新生成 docx，重跑 `python tools/make_report.py` 后会回到“目录域待更新”状态，
   再执行第 2、3 步即可。

已知限制：

* 页数由 `check_report.py` 按字号/行距/图高/表行数估算（本版约 36 页）；
  实际导出为 WPS 34 页 / LibreOffice 35 页，差异来自分页引擎，不是 Word 的精确分页；
* 图 4-4 的图源自带标题与图注，报告图注在下方单独编号，二者文字略有重复，属素材原样；
* 密集路网图（图 4-2）无法同时“全部站名可见”与“零重叠”，本包按验收要求保证零重叠、
  按优先级省略，并在正文注明省略数量；
* `selfcheck` 内部画布尺寸与图 4-2 导出尺寸不同，站名数量分别为 117 与 121（见 §5.1），
  报告统一使用 121/13。
